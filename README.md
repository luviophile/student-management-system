# 学生管理系统（Student Management System）

一个使用 Python 编写的命令行学生管理系统，用于练习面向对象编程、异常处理和 JSON 文件读写。通过终端菜单，可以管理学生姓名和成绩、查看排名，并将数据保存到本地。

仓库中的学生信息均为虚构练习数据。

## 功能

| 菜单选项 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 查看所有学生 | 显示姓名、成绩和成绩等级 |
| 2 | 添加学生 | 输入姓名和成绩，支持整数和小数成绩 |
| 3 | 删除学生 | 根据姓名删除学生 |
| 4 | 修改学生成绩 | 根据姓名更新成绩 |
| 5 | 查看成绩排名 | 按成绩从高到低排列 |
| 6 | 保存学生数据 | 将当前数据写入 `students.json` |
| 7 | 加载学生数据 | 从 `students.json` 重新读取数据 |
| 0 | 退出系统 | 结束程序 |

`StudentManager` 类还实现了按姓名查找学生和计算平均分的方法。其中，平均分目前没有独立的菜单入口。

## 运行环境

- Python 3
- 仅使用 Python 标准库中的 `json`，无需安装第三方依赖

## 快速开始

1. 在仓库页面点击 **Code → Download ZIP**，下载并解压项目。
2. 打开解压后的文件夹，在该文件夹中打开终端。
3. 运行：

   ```bash
   python StudentManager.py
   ```

   Windows 下也可以使用 Python 启动器：

   ```powershell
   py StudentManager.py
   ```

请先进入包含 `StudentManager.py` 和 `students.json` 的文件夹，再运行命令。程序从终端的当前目录读写数据；如果在其他目录通过完整路径启动脚本，可能找不到原来的数据文件。

启动后会自动尝试加载 `students.json`，然后显示菜单：

```text
===== 学生管理系统 =====
1. 查看所有学生
2. 添加学生
3. 删除学生
4. 修改学生成绩
5. 查看成绩排名
6. 保存学生数据
7. 加载学生数据
0. 退出系统
请输入选项：
```

## 使用示例

添加一名学生并保存：

```text
请输入选项：2
请输入姓名:示例同学
请输入成绩:88.5
添加成功！

请输入选项：6
保存成功！

请输入选项：0
系统已退出
```

修改或删除学生时，输入该学生的完整姓名。当前版本允许重名；如果存在同名学生，查找、修改和删除只会操作第一个匹配的记录。

## 成绩规则

成绩必须在 **0～100 分之间（含两端）**，支持小数。添加或修改时，如果输入非数字或超出范围，程序会提示失败。

| 成绩范围 | 等级 |
| --- | --- |
| 90 ≤ 成绩 ≤ 100 | 优秀 |
| 80 ≤ 成绩 < 90 | 良好 |
| 60 ≤ 成绩 < 80 | 及格 |
| 0 ≤ 成绩 < 60 | 不及格 |

## 数据保存与加载

数据文件使用 UTF-8 编码，格式如下：

```json
[
    {
        "name": "示例同学",
        "score": 88.5
    }
]
```

- 添加、删除和修改首先作用于内存。**退出前请选择 `6` 保存；选择 `0` 退出不会自动保存。**
- 保存时会覆盖 `students.json` 原有内容。
- 选择 `7` 重新加载时，会用文件中的数据替换当前学生列表；尚未保存的修改会被覆盖。
- 如果启动时找不到数据文件，程序会提示“文件不存在”，并以空列表继续运行。添加学生后选择 `6` 可以创建数据文件。
- 加载功能已处理文件不存在、JSON 语法错误和成绩超出范围的情况。手动修改 JSON 时，应保留列表结构、`name` 和 `score` 字段，并确保 `score` 是数字；其他结构或类型错误目前可能导致程序报错。

## 项目结构

```text
student-management-system/
├── StudentManager.py   # 学生类、管理器和交互菜单
├── students.json       # 虚构学生数据，保存时会更新
└── README.md           # 项目介绍和使用说明
```

## 练习内容

- 使用 `Student` 和 `StudentManager` 组织数据与功能
- 使用 `@property` 和 setter 统一检查成绩范围
- 使用列表保存学生对象，并按姓名查找记录
- 使用 `sorted()` 和 `lambda` 实现成绩排名
- 使用 `try / except` 处理输入和文件读取异常
- 使用 `with open()` 和 `json` 保存、加载数据
